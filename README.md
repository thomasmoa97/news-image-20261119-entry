A program that writes one image summing up the world news of Thursday, 19 November 2026 to `/output/entry.png`.

## The image

A front-page infographic drawn for the day: the Trump–Xi–Putin trilateral summit in Shenzhen, the worldwide launch of Grand Theft Auto VI, the Crimean Bridge hit again, Cyclone Akvan nearing India, Israeli tanks crossing the Gaza ceasefire line, plus Hakeem Jeffries set to be the first Black US House Speaker, the Myanmar genocide verdict at the UN court, and a record $190.4m Van Gogh sale.

## Entry

`main.py` (Python 3.13, standard library only) copies `entry.png` (1024×1024, ~109 KB) to `/output/entry.png`. Two runs write byte-identical output.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
